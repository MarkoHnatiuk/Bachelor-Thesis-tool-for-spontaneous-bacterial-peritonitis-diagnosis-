# Bachelor's Thesis (tool for spontaneous bacterial peritonitis diagnosis)

For my Bachelor's Thesis I have worked on a bedside tool for spontaneous bacterial peritonitis (SBP) diagnosis using impedance spectroscopy. I've researched about the causes for SBP, how it is being diagnosed and the ways to make it better. The practical part of the thesis was building a circuit that, using electrical impedance, is able to detect and clasify different cells in a sample of ascitic fluids.

The circuit consists of a function generator that provides a wave for frequency alanysis, filters and amplifiers that process the signal and different stages and a lock-in amplifier that turns the signal to a DC signal, allowing detection by Arduino.

Since the topic of microfluids and cell detection/analysis was largely unfamiliar to me, this project proved to be quite a challenge. However, this provided me with a lot of opportunities to grow and learn new things, which I am very grateful for. The project has also greatly improved my circuit building skills.
